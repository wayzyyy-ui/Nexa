# Сценарии для защиты

Что показывать на защите и как заранее проверить это на настоящих устройствах. Показываем только то, что прошло проверку на своих телефоне и ноутбуке; остальное — словами.

Устройства: телефон с Android (APK последней версии) и ноутбук (приложение для ПК или сайт в браузере). Один аккаунт на обоих.

## За неделю до защиты

- [ ] Открыть NEXA и войти: бесплатный проект Supabase засыпает примерно после недели без запросов. Заснул — разбудить в панели Supabase (Restore) и потом открывать NEXA хотя бы раз в несколько дней.
- [ ] `npm run db:check` — в базе есть всё из `supabase/*.sql`. Чего-то нет — вставить названные файлы в SQL Editor.
- [ ] Ассистент отвечает (квота Gemini не кончилась), погода показывается.
- [ ] Прогнать все сценарии ниже по разу и отметить, что прошло.
- [ ] Записать видео всех сценариев с экрана — запасной вариант, если на защите не будет интернета.

## В день защиты

- [ ] Телефон и ноутбук заряжены, в одной сети Wi-Fi, интернет есть (или раздача с телефона, проверенная заранее).
- [ ] На телефоне разрешены уведомления NEXA; на Xiaomi / Redmi / POCO включён «Автозапуск» (Настройки → Безопасность → «Работа в фоне»).
- [ ] NEXA открыта на обоих устройствах, вход выполнен, оба видят друг друга «в сети».
- [ ] Видео-запасной вариант лежит на ноутбуке.

## 1. Вход по QR (около 30 секунд)

Показывает: вход без пароля, как в мессенджерах.

1. На ноутбуке выйти из аккаунта (заранее), на экране входа — «Войти по QR».
2. На телефоне: Настройки → значок QR слева сверху → «Сканировать QR».
3. Телефон спрашивает «Разрешить вход?» → «Разрешить».

Ожидается: ноутбук сам входит за 2–3 секунды, данные аккаунта на месте.
Не вышло: войти по почте кодом из письма (письмо может идти минуту — проверить заранее).

## 2. Устройства в одной системе (около 30 секунд)

Показывает: главную идею NEXA.

1. На ноутбуке — Главная, «Мои устройства»: телефон «в сети», видны заряд, память, сеть.
2. Свернуть NEXA на телефоне и подождать около минуты — на ноутбуке телефон становится «не в сети» с «Был в сети только что».

Ожидается: статус меняется сам, без обновления страницы.

## 3. Передача текста и файла (около минуты)

1. На телефоне скопировать ссылку → «Поделиться» → «Отправить в NEXA» → ноутбук.
2. На ноутбуке приходит уведомление с «Открыть».
3. На ноутбуке открыть фото в «Файлах» → «Отправить на устройство» → телефон.

Ожидается: на телефоне плашка «Файл для вас» → «Открыть».
Не вышло: проверить, что оба «в сети»; файл в любом случае лежит в «Файлах» аккаунта на телефоне.

## 4. Найти телефон (около 30 секунд)

1. На ноутбуке: экран телефона → «Найти».
2. Телефон вибрирует и показывает «Устройство ищут» → «Нашёл».

Ожидается: на ноутбуке «Нашлось».
Дополнительно, только если заранее проверено: то же при закрытой NEXA на телефоне (приходит push со звуком). Это зависит от Firebase и настроек телефона — на защите пробовать, только если прошло дома несколько раз подряд.

## 5. Ассистент (около минуты)

1. Написать «открой файлы» — раздел открывается сразу: это поняла своя нейросеть NEXA mini-1 на устройстве, без запроса к Gemini.
2. Спросить обычный вопрос — ответ печатается по словам.
3. Приложить PDF (скрепка) → «Кратко перескажи».

Ожидается: команда — мгновенно, ответ — за несколько секунд.
Не вышло (нет ответа от Gemini): показать команды mini-1 — они работают и без сети.

## 6. Заметки на двух устройствах (около минуты)

1. На ноутбуке создать заметку с чек-листом.
2. На телефоне она появляется сама; отметить пункт.
3. Выключить на телефоне интернет, изменить заметку, включить — изменение уходит на ноутбук.

Ожидается: правки видны на другом устройстве за секунды, без сети ничего не теряется.

## Что на защите не показывать без отдельной проверки

Это проверялось только на имитаторе или эмуляторе, на настоящих устройствах — нет (подробности в файлах `docs/`):

- «Рядом» — передача без интернета между двумя телефонами;
- передача файлов напрямую по Wi-Fi между телефоном и ПК (`docs/local-transfer.md`);
- общий буфер обмена с шифрованием между ПК и телефоном;
- «Где устройство?» при закрытой NEXA на телефоне;
- сайт на айфоне;
- загрузка больших файлов с обрывом сети.

Прошло дома несколько раз — можно перенести в сценарии выше.

## Ограничения, о которых честно сказать (если спросят)

- Связь между устройствами работает, пока NEXA открыта: Android «замораживает» приложения в фоне. В фоне работают только push («Найти»), напоминания и виджеты.
- Данные хранятся в Supabase (Европа), ассистент — Gemini (Google). Для настоящего запуска в России их нужно заменить на российские сервисы (закон о персональных данных 152-ФЗ).
- Приложение для Android раздаётся файлом APK, не через магазин: телефон предупреждает об установке из неизвестного источника.
