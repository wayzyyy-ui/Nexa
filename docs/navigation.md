## Адреса и история (навигация)

- Модуль `src/lib/router.js` — History API, без библиотек маршрутизации. Экран = `{ tab, sub, dev }`; источник правды — состояние NexaApp (`tab`, `activityOpen`, `aboutOpen`, `securityOpen`, `devicesOpen`, `openDeviceId`), эффект в NexaApp зовёт `navigate()` при каждой смене экрана, Назад/Вперёд браузера → `onRoute` → те же setState.
- Карта адресов: `/` Главная, `/today`, `/assistant`, `/media`, `/files`, `/settings`; поверх раздела — `/activity`, `/about`, `/security`, `/devices` («Все устройства»), `/notes` («Заметки», над «Сегодня»), `/device/<id>` (экран устройства). Служебных и административных экранов в NEXA нет; новые такие — без адреса в sitemap и ссылках. Заголовок вкладки — `titleOf` («Файлы · NEXA», у устройства — его имя).
- Правила истории (`planNavigate` — чистая функция, тесты `tests/router.test.mjs`): с Главной в раздел — `pushState`; между разделами (кроме Главной) — `replaceState` (свайпы и панель историю не раздувают); на Главную нажатием — шаг назад к записи Главной; экран поверх раздела — своя запись, «Назад» на экране / Esc — шаг назад; из экрана устройства в другой раздел — записи поверх уходят, раздел встаёт сразу над Главной. Итог: Назад с любого раздела → Главная, с Главной — уход с сайта (в приложении — свернуть).
- Окна, меню, шторки (`[role="dialog"]`, `[role="menu"]`, `.nx-notes`) — своя запись с тем же адресом: следит `MutationObserver` (`syncLayers`, не чаще раза за кадр). Назад закрывает верхнее окно нажатием Esc (`pressEscape`); закрыли крестиком / Esc — запись окна убирается сама. Не считаются: экран входа (`.nx-auth-gate`), уходящие окна (`.nx-leaving`, `.nx-fade-leaving`), пришедшие сами карточки (`.nx-cont-offer`, `.nx-find-overlay`) и всё с `data-nx-noback` (блокировка `LockOverlay`). Новое окно достаточно сделать `role="dialog"` с закрытием по Esc.
- Шаги назад (`history.go`) — по очереди: следующий ждёт popstate (страховка 600 мс). Копия стопки записей — `sessionStorage nexa-nav` (переживает перезагрузку вкладки); номер записи — `history.state.nx.i`. `history.scrollRestoration = "manual"`; при Назад/Вперёд между экранами прокрутка наверх (`scrollTopNow`), в приложении между разделами — тот же въезд `navTransition`, на сайте без своей анимации (браузер сам показывает жест «назад»).
- Запуск (`bootRoute`, до первого кадра): приложение (Android) всегда с Главной; корень сайта — Главная; прямая ссылка (`/files`) — свой экран, а под ним запись Главной (Назад → Главная); неизвестный адрес → Главная с заменой записи; перезагрузка — тот же экран (запись истории помнит больше адреса: `/device/<id>` из «Все устройства» вернётся к списку). `/device/<id>` без такого устройства (когда список известен) → раздел. `?pair=` / `?login=` остаются в адресе до NexaApp и убираются `replaceState(history.state, …)` — запись NEXA не теряется. Прежние `nexa-tab` (local/session) больше не используются и удаляются.
- Ассистент: вернулись Назад/Вперёд — открывается тот же диалог (`currentChatRef`).
- Хостинг: `vercel.json` → `rewrites` `/((?!api/)[^.]*)` → `/index.html` (адреса без точки и не `/api/`; `version.json`, `nexa.apk`, `sitemap.xml`, `manifest.webmanifest`, `/assets/*`, картинки — как есть). Сборка с `base` «/» (по умолчанию) — относительный `--base ./` ломает `/device/<id>`. Android WebView (Capacitor, html5mode) сам отдаёт index.html на адреса без точки.
