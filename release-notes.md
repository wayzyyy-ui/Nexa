# Что нового в следующей версии NEXA.
# Каждый пункт — строка, начинающаяся с «- ». Строки с # — пояснения, в приложение не попадают.
# npm run copy:apk (и release:android) возьмёт пункты отсюда в public/version.json → поле notes.
# Перед каждым выпуском замените пункты на новые.

- Резервная копия: заметки, диалоги, расписание и файлы — в один файл и обратно
- Набранный вопрос ассистенту не пропадает при переходе в другой раздел
- Оборванный ответ ассистента честно помечен — его можно повторить
- Синхронизация: приходят все записи, даже если их больше тысячи
- Один слишком большой диалог больше не мешает сохранить остальные
- Главная на телефоне: шапка и поиск больше не наезжают друг на друга
- NEXA больше не попадает в резервную копию телефона вместе со входом в аккаунт
