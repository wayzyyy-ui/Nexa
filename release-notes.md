# Что нового в следующей версии NEXA.
# Каждый пункт — строка, начинающаяся с «- ». Строки с # — пояснения, в приложение не попадают.
# npm run copy:apk (и release:android) возьмёт пункты отсюда в public/version.json → поле notes.
# Перед каждым выпуском замените пункты на новые.

- NEXA для компьютера: своё окно, значок у часов, запуск вместе с компьютером, обновляется сама
- Компьютер теперь тоже устройство: имя, заряд, сеть и место на диске
- Общий буфер обмена: скопировали на одном устройстве — «Скопировать» на другом (включается в Настройках)
- Уведомление «Скопировано на …» с кнопкой «Скопировать», даже когда NEXA на телефоне закрыта
- Ctrl+← и Ctrl+→ переключают разделы на компьютере
- Ссылки в приложении для компьютера открываются в браузере, файлы — в своих программах
- Ровнее подписи устройств и ИИ — Ассистента на Главной
