# Что нового в следующей версии NEXA.
# Каждый пункт — строка, начинающаяся с «- ». Строки с # — пояснения, в приложение не попадают.
# npm run copy:apk (и release:android) возьмёт пункты отсюда в public/version.json → поле notes.
# Перед каждым выпуском замените пункты на новые.

- Обновление прямо из приложения: скачивание с прогрессом, проверка файла и установка без браузера
- Блок «Доступно обновление» на Главной и в Настройках — со списком изменений и кнопкой «Позже»
- Проверка новой версии не чаще раза в 6 часов, «Проверить» в Настройках — сразу
- Push-уведомления для «Найти устройство», когда NEXA на телефоне закрыта
